PRISM / vLLM Disaggregation Command Log
========================================

Collected vLLM serve, proxy, and AIPerf commands from the simple workload sweep and encoder-heavy workload sweep.

Workloads:
- Simple: Qwen/Qwen2-VL-2B-Instruct, image 512x512, concurrency 4, output 256 tokens, 50 requests + 10 warmup.
- Encoder-heavy: Qwen/Qwen2-VL-2B-Instruct, image 1024x1024 + 1 synthetic video, video 4s x 4 FPS = 16 frames, concurrency 8, output 256 tokens, 100 requests + 10 warmup.

Common setup used in most shells
--------------------------------

module load gcc/13.2.0 cuda/12.8 python/3.12.11

export PRISM_ROOT=$SCRATCH/PRISM_env
source $PRISM_ROOT/venvs/prism-env/bin/activate

export HF_HOME=$PRISM_ROOT/.cache/hf_home
export TRANSFORMERS_HOME=$PRISM_ROOT/.cache/transformers
export VLLM_CACHE_ROOT=$PRISM_ROOT/.cache/vllm
export TORCHINDUCTOR_CACHE_DIR=$PRISM_ROOT/.cache/torchinductor
export TRITON_CACHE_DIR=$PRISM_ROOT/.cache/triton
export TMPDIR=$PRISM_ROOT/.cache/tmp

export TORCH_LIB=$PRISM_ROOT/venvs/prism-env/lib/python3.12/site-packages/torch/lib
export LD_LIBRARY_PATH="$TORCH_LIB:${LD_LIBRARY_PATH:-}"

export MODEL="Qwen/Qwen2-VL-2B-Instruct"

Useful cleanup:

pkill -f "vllm serve" || true
pkill -f "disagg_epd_proxy.py" || true

For full E+P+D with NIXL, also use this in prefill/decode shells:

export OPENSSL3_LIB=/opt/apps/cuda/12.8/nsight-systems-2024.6.2/host-linux-x64
export TORCH_LIB=$PRISM_ROOT/venvs/prism-env/lib/python3.12/site-packages/torch/lib
export LD_LIBRARY_PATH="$OPENSSL3_LIB:$TORCH_LIB:${LD_LIBRARY_PATH:-}"


============================================================
SIMPLE WORKLOAD SWEEP
============================================================

SIMPLE 1: Aggregated A100/A100, 2 GPU, TP=2
-------------------------------------------

export MODEL="Qwen/Qwen2-VL-2B-Instruct"
export PORT=8000

CUDA_VISIBLE_DEVICES=0,1 PYTHONUNBUFFERED=1 VLLM_LOGGING_LEVEL=INFO \
vllm serve "$MODEL" \
  --host 0.0.0.0 \
  --port "$PORT" \
  --tensor-parallel-size 2 \
  --gpu-memory-utilization 0.90 \
  --max-num-seqs 16 \
  --limit-mm-per-prompt '{"image":1}'

export OUT_DIR=$SCRATCH/PRISM/artifacts/qwen2vl_2b_aggregated_tp2_2gpu_img512_c4_out256

aiperf profile \
  --model "$MODEL" \
  --url http://localhost:$PORT \
  --endpoint-type chat \
  --image-width-mean 512 \
  --image-height-mean 512 \
  --concurrency 4 \
  --request-count 50 \
  --warmup-request-count 10 \
  --use-server-token-count \
  --prompt-output-tokens-mean 256 \
  --prompt-output-tokens-stddev 0 \
  --gpu-telemetry "pynvml" \
  --extra-inputs ignore_eos:true \
  --output-artifact-dir "$OUT_DIR"

    \"ec_connector\":\"ECExampleConnector\",
    \"ec_role\":\"ec_consumer\",
    \"ec_connector_extra_config\":{
      \"shared_storage_path\":\"$EC_SHARED_STORAGE_PATH\"
    }
  }"

# Shell 2: A100 encoder EC producer

CUDA_VISIBLE_DEVICES=0 PYTHONUNBUFFERED=1 VLLM_LOGGING_LEVEL=INFO \

  --host 127.0.0.1 \
  --port "$ENCODE_PORT" \

  --enforce-eager \
  --no-enable-prefix-caching \
  --max-num-batched-tokens 8192 \
  --max-num-seqs 16 \

  --ec-transfer-config "{
    \"ec_connector\":\"ECExampleConnector\",

    \"ec_connector_extra_config\":{
      \"shared_storage_path\":\"$EC_SHARED_STORAGE_PATH\"

Notes
-----

- For E+PD, encoder = EC producer and PD = EC consumer.
- For full E+P+D:
  - Encoder = EC producer.
  - Prefill = EC consumer + NIXL KV producer.
  - Decode = NIXL KV consumer.
- Full E+P+D requires NIXL and OpenSSL 3 library in LD_LIBRARY_PATH.
- For cross-node NIXL, VLLM_NIXL_SIDE_CHANNEL_HOST must be the real hostname, not localhost.
- Encoder kept --enforce-eager because encoder CUDA graph capture crashed earlier.
- Prefill/decode commands omit --enforce-eager for performance.
